## Notes

- **Release gate passed**: no real reference was called a ghost. Nine real
  references are `UNVERIFIED (not in bibliographic indexes)` — FDA and WHO pages,
  a Microsoft blog post, a CDC dashboard, a lab manual, a PsyArXiv preprint — which
  is the honest state for documents indexes never held. Phase 4 fetches URLs.
- **How the number moved**: 20.8 % → 4.7 % → 0.0 % false ghosts across three
  rounds, each failure turned into a regression test in `tests/test_resolve.py`.
  Round 1: ACM full-name author lists broke title segmentation (11 cases), books
  and web pages had no home (9), dotless arXiv ids and two-word titles (2).
  Round 2: `(Publisher, Year)` in segments, Nature-style annotation sentences
  hijacking the year delimiter, blogs/manuals/OSF markers. Round 3: a
  proceedings-volume record matching the venue segment passed as a paper; Open
  Library records without author agreement passed as books.
- **Providers**: Crossref + Semantic Scholar first; arXiv, Open Library and
  OpenAlex only before a ghost call. OpenAlex's free tier is a daily budget of
  ~100 searches and was exhausted for most of this run; the design treats it as
  best effort and the numbers above were reached without it.
- **Mutated real references** (title kept, first author replaced, year +6):
  65 % `AMBIGUOUS`, 25 % `RESOLVED (low confidence)`, 5 % `RESOLVED` — one slip,
  where the replaced surname happened to occur elsewhere in the string. Never
  `GHOST`, which is the point of the state.
- Reproduce: `uv run python scripts/eval_ghosts.py --refresh` (live; ~35 min with
  polite intervals, results cached under the platform cache dir).
