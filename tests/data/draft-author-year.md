# Author-year citations, checked

## Models

Attention-only sequence models changed what a translation system costs to train:
on the WMT 2014 English-to-French task the Transformer reached its state-of-the-art
BLEU score after training for 3.5 days on eight GPUs (Vaswani et al., 2017).
Structure prediction followed the same path, and AlphaFold predicts protein
structures with atomic accuracy even where no similar structure is known
(Jumper et al., 2021).

## Tooling

NumPy is the foundational array programming library of the Python scientific
ecosystem (Harris et al., 2020). The same library underpins the interoperability
of the whole stack (ibid.). SciPy builds on it with the fundamental algorithms for
scientific computing in Python (Virtanen et al., 2020; [5]).
